# Structure Planner

Next.js progressive web app that generates plans for small structures (sheds, decks, cabins, garages) from photos and a few questions.

## Features
- Upload site / inspiration photos
- Choose structure type and dimensions
- Select materials and add notes
- Generates 2D floor plan (SVG), material estimates, and build steps
- Print / PDF export

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech
- Next.js 16 + React 19
- Tailwind CSS
- TypeScript
